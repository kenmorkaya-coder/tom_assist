# V18 anchored causal-binding diagnostic

Evaluate both existing adapters (4,380 and 5,172 cumulative steps) on 60 frozen development records. Four anchor groups reproduce the three exact V16 causal regression sentences and the exact shared V17 overlapping-name failure. For each anchor, compare five conditions: unchanged anchor, rename the shared site prefix on both entities, change only the target site prefix, replace both entity names with short neutral names, and change the causal wording while preserving entity order. Each condition has its canonical sentence, an equivalent result-form paraphrase, and a reversed-role contrast. There are 20 triplets and 12 records per condition.

Compare canonical variants within each anchor first; aggregate triplet scores are secondary. Renaming changes lexical identity as well as tokenization; short names also change lexical content and overlap. These interventions cannot establish a pure length effect or fully isolate individual token features. Report exact source and target matches and semantic graph differences. Separate wrong spans from correct entity names bound to the wrong roles. Report original anchor reproduction by checkpoint against saved V16 and V17 predictions; if it fails to reproduce, inspect saved token streams/runtime provenance before attributing a training cause.

Both checkpoints use the same pinned model, unchanged prompt/parser, greedy decoding and 4,096-token ceiling. Freeze source, labels, protocol, tests, anchor evidence and adapter hashes before inference. Validate all label roundtrips and reversed-role contrasts. After completion reparse all 120 raw predictions and verify scores, token IDs/finish reasons and provenance before reporting.

This is diagnostic development data built from exposed failures, not held-out evidence. Retain the 4,380-step checkpoint regardless of these results. V12 and V15 remain RED. No training, model selection, matrix or Tree run is authorized by this protocol. At completion identify the smallest supported curriculum change; no silent follow-on job. Preserve all prior frozen artifacts and unrelated work.
